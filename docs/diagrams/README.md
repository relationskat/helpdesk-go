# Модели HelpDesk Go

Семь моделей целевой системы для документа требований 1.0. Каждому `.puml` соответствует одноимённый `.png`. Диаграммы ссылаются на стабильные FR и US из [спецификации](../01-requirements.md).

Экспорт: Java и PlantUML 1.2025.2, встроенный движок Smetana (внешний Graphviz не нужен). Загрузить официальный JAR PlantUML этой версии и из корня репозитория выполнить:

```sh
PLANTUML_JAR=/path/to/plantuml-1.2025.2.jar sh scripts/render-diagrams.sh
```

PNG необходимо обновлять одновременно с исходниками. Сам JAR в репозиторий не включается.
