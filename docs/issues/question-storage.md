# Как сохранять заявки после перезапуска?

Метка: question

Сейчас данные в памяти и теряются после остановки. Предлагается SQLite с миграциями. В ЛР2–4 согласовать файл хранения, резервное копирование и обработку ошибки записи. Критерий решения: заявки и комментарии доступны после перезапуска, проверка автоматизирована.
